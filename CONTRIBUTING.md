# Contributing

Please open an issue with a minimal Markdown example, expected behavior, Python version and operating system. Do not include private documents or credentials.

For changes, add a regression test, run `python -m unittest discover -s tests -v`, and describe any parsing limitations. Keep the tool offline and dependency-free.

Useful future work: a complete CommonMark parser option, heading-anchor validation, and configurable exclusions. These are proposals, not implemented features.
